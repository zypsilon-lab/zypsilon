ZYpsilon · 投影实验室

一个免费的交互式三维画法几何实验室。直观呈现正投影（蒙日法）、轴测图、透视、阴影与剖切是如何作出的：投影面、立体、投射线，以及在投影面上形成的图像。全部在浏览器中运行，无需安装。

打开实验室

以中文打开，免费，无需注册。

可以做什么

  • 正投影（蒙日法）：三个投影面（正立面 V、水平面 H、侧立面 W），立体位于第一象限。展开角度滑块把投影面摊成图纸：主视图、俯视图和左视图，附投影轴与投影连线。
  • 正轴测与斜轴测：正轴测有正等测，高级模式下还有正二测和正三测；斜轴测有骑士投影、缩短骑士投影、单测投影，以及平面投影、缩短平面投影和军事投影。
  • 透视：平行透视（一个灭点）、成角透视（两个）和三点透视，附视平线、基线、主点和灭点。
  • 截平面与剖切：真正切开立体：被切去的部分隐约可见，截断面着色；在蒙日法中展开后用经典的圆弧作图得到截断面实形。
  • 阴影：平行光线（太阳）或点光源（灯）：本影、落影，以及逐个顶点的引导作图。
  • 相贯实验室：用截平面法求两个立体的相贯线：选择立体 A 和 B，设定轴线与位置，跟随作图。
  • 图纸与 PDF：可选 A4、A3 或 A2，尺寸以厘米计，图样按 1:1 绘制；可下载 PNG 或 PDF，PDF 中带有可重新打开该图的链接。

使用方法

  1. 在左侧面板选择投影类型。
  2. 拖动旋转视图，Shift 加拖动平移，滚轮或双指缩放。触屏上一指旋转，两指平移并缩放。
  3. 选择或输入立体尺寸，需要时开启截平面、阴影或尺寸。
  4. 把图样排在图纸上，下载 PNG 或 PDF，也可复制链接重新打开该场景。

适用对象

适合艺术高中、技术学校以及建筑、工程和设计专业中学习画法几何、制图与表现的学生和教师。平板电脑和交互式白板上同样可用。

常见问题

ZYpsilon 免费吗？
学习、教学和研究免费，采用 PolyForm Noncommercial 1.0.0 许可。学生、教师、学校、大学和公共研究机构可自由使用。商业用途（例如用于图书、收费课程或带广告的网站）需要书面许可：info@zypsilon.com。
需要安装吗？
不需要，直接在浏览器中运行。也可以从 GitHub 下载仓库后打开 index.html，离线同样可用。
有哪些语言？
意大利语、英语和简体中文。应用按浏览器语言打开，可用面板顶部的切换器更改。
会收集个人数据吗？
没有账号，也不会向服务器发送内容：场景、PNG 和 PDF 都在你的设备上生成。Google Analytics 统计仅在官方网站加载，且须在你同意之后。
